- 版本：**0.7.5**（App.csproj / Setup.csproj / Installer.cs / README 已统一，关于窗口读程序集元数据自动跟随）。
- 本次改动（相对 0.7.4）：
  1. **图片片段旋转**：右侧「片段操作」新增旋转按钮（仅图片可见），点击顺时针 90° 循环（0/90/180/270）。工程内记录旋转标记（`Clip.Rotation`），不改写原图、不重新编码、不损失画质；预览/缩略图/导出/人脸检测均按旋转后的方向处理。

## 五、打包流程（改代码后重打版本）

```bash
# 1) 升版本号：App.csproj / Setup.csproj / Installer.cs(DisplayVersion) / README.md
# 2) 发布主程序（须还原 RID，勿加 --no-restore）
dotnet publish src/MemoriesStudio.App/MemoriesStudio.App.csproj -c Release -r win-x64 \
  --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibraries=true -p:DebugType=none -o build/publish0XX
# 3) 组载荷：publish0XX/MemoriesStudio.exe + 上一版 payload 的 ffmpeg/ libvlc/ models/（models 必带 onnx，否则 selftest FAIL）
# 4) 压载荷
python tools/make_payload.py build/payload0XX src/MemoriesStudio.Setup/payload.zip
# 5) 发布安装器（产物名 MemoriesStudioSetup.exe）并改名 installer/MemoriesStudio-0.7.X-Setup.exe
dotnet publish src/MemoriesStudio.Setup/MemoriesStudio.Setup.csproj -c Release -r win-x64 \
  --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibraries=true -p:DebugType=none -o installer_out0XX
# 6) 自检 + 静默重装恢复关联
MemoriesStudio-0.7.X-Setup.exe --selftest build/selftest_0XX.txt
MemoriesStudio-0.7.X-Setup.exe --install <安装目录>
```

## 六、已知环境坑

- **git 直连 GitHub 间歇不稳定**：进程环境变量曾注入 `http_proxy/https_proxy`。本地已设 `git config --local http.proxy ""` 绕过；仍不稳时用 GitHub REST API + `gh auth token` 推送（参考 `push_v073.py`，改 base commit / changed 列表 / 提交信息即可）。
- **publish 必须带还原**：`-r win-x64 --self-contained` 若加 `--no-restore` 会报 NETSDK1047（资产文件无 win-x64 目标）。
- **安装器产物名**：publish 出来是 `MemoriesStudioSetup.exe`（不带点），复制时别写成 `MemoriesStudio.Setup.exe`。
- **单文件自包含**：产物约 320 MB，含 FFmpeg ~97MB、libVLC、OpenCV、.NET 运行库，首次 publish/打包较慢（数分钟）。
- **旧工程字幕区间**：0.7.4 之前的工程若已写入字幕，`Caption.End` 保留原值，不受默认值影响。
- **运镜抖动问题已关闭**：第 3 幅轻微抖动为 zoompan 整数取整（0.2~0.6px），用户确认肉眼无感、明确不改代码。`ExportEngine.cs` 的 `ss` 保持原值 2.0/1.5。
